Temperature Converter

A simple console application written in Python for converting temperatures between Celsius, Fahrenheit and Kelvin. User inputs original temperature, select the source and target temperature scales - the program displays the result.

Features:
- convert temperatures between Celsius, Fahrenheit and Kelvin
- support all nine combinations, including converting within the same scale
- display result with two decimal places
- validate temperature values against absolute zero

Requirements:
Python 3.12 or later
No external libraries are required

Installation:
1. Clone the repository: git clone https://github.com/usfi0410/temperature-converter.git
2. Navigate to the project directory: cd temperature-converter

Usage:
Run the application: python temperature_converter.py
Enter the temperature, select the original scale (C, F, or K), and select the target scale.

Example:

=== Temperature Converter ===
Enter temperature: 25
From (C/F/K): C
To (C/F/K): F
Result: 25.00 C = 77.00 F
Convert another temperature? NO
